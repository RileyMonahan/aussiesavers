# Aussie Savers

Australian household bill comparison website for electricity, gas and internet.

See [`CLAUDE.md`](./CLAUDE.md) for the full project brief and implementation notes.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app. The 3-step flow lives at:

- `/` — Your Details
- `/upload` — Upload Bills
- `/compare` — Compare & Save
